# Extensão AuraVoice - LMNT Session Sync Master

Esta extensão permite que o Administrador sincronize a sessão ativa do Playground da LMNT com 1 clique direto no AuraVoice.

## Como Instalar no Google Chrome / Edge / Brave:

1. Abra o navegador e acesse: `chrome://extensions/`
2. No canto superior direito, ative a chave **"Modo do desenvolvedor"** (Developer mode).
3. Clique no botão **"Carregar sem compactação"** (Load unpacked).
4. Selecione esta pasta:
   `C:\Users\User\Desktop\gerelab\public\extension`
5. A extensão **AuraVoice - LMNT Session Sync Master** aparecerá no topo do seu navegador!

## Como Usar:

1. Faça login na sua conta no site: `https://app.lmnt.com`
2. Clique no ícone da extensão AuraVoice no topo do Chrome.
3. Clique no botão **"Puxar & Enviar Token de Sessão"**.
4. Pronto! O servidor receberá a sessão e ativará o **Bypass de Voz Playground** imediatamente como prioridade #1!
